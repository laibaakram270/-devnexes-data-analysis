# E-Commerce Sales Performance & Customer Retention Dashboard

## Project Overview
Analyzed 541,909 sales records to derive customer retention metrics for Devnexes Digital Solutions.

## Tech Stack
Python, Pandas, NumPy, Matplotlib, Seaborn, Streamlit

## How to Run
1. `pip install -r requirements.txt`
2. `python week1_clean.py`
3. `python week2_rfm.py`
4. `python -m streamlit run app.py`

## Key Features
- Data Cleaning and Preprocessing
- RFM Customer Segmentation
- Monthly Cohort Retention Matrix
- Interactive Streamlit Dashboard with date filters
